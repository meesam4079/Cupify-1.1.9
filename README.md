# Cupify

Custom cup ordering and management application.

## Features
- Custom cup design form
- Menu browsing & ordering
- Admin dashboard (products, orders, staff, reports)
- Staff panel
- User authentication (login / register)
- Order tracking

## Tech Stack
- React + TypeScript
- TanStack Router & Query
- Tailwind CSS
- Better Auth
- Vite
- PGLite / Postgres

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080)

## Scripts
- `npm run dev` – Start development server
- `npm run build` – Production build
- `npm run typecheck` – TypeScript check
